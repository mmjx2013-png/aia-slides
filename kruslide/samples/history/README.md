# อยุธยา · ราชธานีบนเกาะกลางแม่น้ำ (ตัวอย่างสไลด์ประวัติศาสตร์ "แบบที่หนึ่ง" ของ KruSlide)

สไลด์ 10 หน้า ภาษาไทย ไม่มีเสียงบรรยาย: ผู้นำเสนอพูดเอง กดทีละจังหวะ (beat) ทุกอย่างอยู่ในโฟลเดอร์นี้ ไม่ต้องต่ออินเทอร์เน็ต

## เปิดอย่างไร
- **ง่ายที่สุด:** ดับเบิลคลิก `index.html` (Chrome / Edge / Safari) แล้วกด **F** เพื่อเต็มจอ
- หรือเปิดผ่านเว็บ: `python3 -m http.server` ในโฟลเดอร์นี้ แล้วเปิด `http://localhost:8000/`
- ใช้ได้กับโปรเจกเตอร์ทุกขนาด (เวทีขนาด 1920×1080 ย่อขยายตามจอ) ลูกโลกใช้ WebGL2 ถ้าเครื่องไม่มี จะแสดงลูกโลกแบบวาดแทนโดยอัตโนมัติ

## ลำดับและสิ่งที่ควรพูด (ราว 8–10 นาที)
1. **จากโลกสู่เกาะเมือง** (4 จังหวะ) ลูกโลกหมุนช้า ๆ ถามคำถามของวันนี้: *ทำไมเกาะเล็ก ๆ กลางแม่น้ำจึงเป็นราชธานีได้นานกว่า 400 ปี?* กดต่อ 3 ครั้ง กล้องบินลง เอเชียตะวันออกเฉียงใต้ → ประเทศไทย (เส้นเขตแดนสีทองวาดตัวเอง แม่น้ำเจ้าพระยาไหลลงอ่าวไทย) → ภาพดาวเทียมเปลี่ยนเป็นแผนภาพ เกาะเมืองปรากฏ แม่น้ำ 3 สายวาดตัวเอง
2. **ทำไมต้องเป็นเกาะนี้?** (4) แผนที่ "Judia" ของ Valentijn พ.ศ. 2269 ทับลงบนเกาะเดียวกัน → ① ป้อมปราการน้ำ: กำแพงวาดรอบเกาะ น้ำหลากท่วมที่ราบรอบเมือง → ② ประตูสู่ทะเล: กล้องถอยไปถึงอ่าวไทย เรือแล่นทวนน้ำมาถึงเมือง → ③ ที่ราบลุ่ม: ทุ่งนาแผ่ออกจากแม่น้ำ
3. **ราชธานี 417 ปี** (2) แผนที่ยกตัวขึ้นเป็นภาพวาดเมืองปี 2205 ตัวเลขย้อนเวลาจาก 2569 ไป **1893** → กดต่อ: นับ **417** ปี เส้นเวลาวิ่งถึง 2310 **ให้นักเรียนออกมาลากเส้นเวลา** (ลากตรงไหนของแถบก็ได้) ดูเหตุการณ์ 2112, 2127, 2173, 2205, 2310
4. **ทางแยกการค้าโลก** (4) ภาพวาดเปิดเป็นลูกโลก → เส้นทางตะวันออก (จีน ญี่ปุ่น) วาดตัวเอง มีเรือแล่น → ตะวันตก (อินเดีย เปอร์เซีย อ้อมแอฟริกาไปยุโรป) และเส้นประทางบกไปมะริด → แผนที่เรือ VOC ราว พ.ศ. 2178 เป็นหลักฐาน
5. **วัดพระศรีสรรเพชญ์** (3) กล้องดำลงเกาะในวงกลมระบุตำแหน่ง → วงกลมซูมเข้าเขตพระราชวังหลวง (วัดในวัง ไม่มีพระสงฆ์จำพรรษา) → เจดีย์ 3 องค์ถูกวงทีละองค์
6. **วัดไชยวัฒนาราม** (3) วงกลมขยายเต็มจอ บินลงหมุดฝั่งตะวันตก แล้วกลายเป็นภาพมุมสูงจริง → วงจักรวาลแผ่จากปรางค์ประธาน (เขาพระสุเมรุ) → ภาพกลางคืนเลื่อนเข้า นับความสูงราว 35 เมตร
7. **เสียกรุง พ.ศ. 2310** (3) ภาพเมืองค่อย ๆ หมดสี ตัวเลขนับจาก 1893 ถึง 2310 → เส้นไฟกวาด เผยพระพุทธรูปไร้เศียร → วงกลมแผนที่: ลูกศรจากอยุธยาลงไปกรุงธนบุรี
8. **เศียรพระในรากโพธิ์** (2) แสงค่อย ๆ เปิดที่พระพักตร์ → นับจำนวนปีตั้งแต่ 2310 ถึงวันนี้ และมารยาทเวลาไปถ่ายภาพ
9. **มรดกโลก พ.ศ. 2534** (2) เลขนับจาก 2310 ถึง 2534 → ภาพหดเป็นเหรียญกลมเกาะบนลูกโลก "จากเกาะเล็ก ๆ สู่มรดกของคนทั้งโลก"
10. **ทบทวน 3 ข้อ** (3) ให้นักเรียนกดเลือกคำตอบบนจอก่อน → กดถัดไปเพื่อเฉลย ข้อ 3 คือคำตอบของคำถามแรก: ป้ายบนแผนที่บอกว่าแม่น้ำเป็นทั้งคูเมือง ทางค้าขาย และที่ราบปลูกข้าว → แผ่นแหล่งข้อมูลและเครดิตภาพเลื่อนขึ้น

## ความถูกต้อง
- ปี พ.ศ. ตามหนังสือเรียนไทย ข้อเท็จจริงทุกข้ออ้างอิงตามแผ่นแหล่งข้อมูล (UNESCO, Baker & Pasuk 2017, Britannica, กรมศิลปากร)
- เกาะเมืองและแม่น้ำ 3 สายเป็น **แผนภาพอย่างง่าย** (เขียนไว้บนสไลด์แล้ว) เส้นทางการค้า ระดับน้ำ และทุ่งนาเป็นภาพประกอบโดยประมาณ
- เครดิตภาพและสัญญาอนุญาตครบใน `credits.md`
