ให้นักเรียนออกมาลากจุดยอดจุดใดก็ได้ (แตะใกล้จุดก็จับได้) มุมวัดเป็นองศาเต็มทุกครั้ง ผลรวมขวามือเป็น 180° เสมอ ถามห้อง: ถ้าฉีกมุมทั้งสามออกมาวางต่อกันจะได้อะไร กด → มุมทั้งสามฉีกออกแล้วลอยไปเรียงบนไม้โปรแทรกเตอร์ เป็นเส้นตรงพอดี (180°) ลากจุดยอดตอนนี้ได้ มุมที่เรียงไว้เปลี่ยนตาม แต่ยังเป็นเส้นตรงเสมอ กด → รูปสามเหลี่ยมเปลี่ยนรูปเองหลายแบบ เส้นตรงไม่เปลี่ยน สรุป: มุมภายในรวม 180° ทุกรูป

ต่อด้าน BC ไปถึง D มุม ACD เป็นมุมภายนอก ลากจุด A หรือเลื่อน B, C บนไม้บรรทัด ตัวเลขเปลี่ยนตาม กด → สำเนามุม B เลื่อนตามไม้บรรทัดไปที่ C (มุมแบบนี้เรียกว่ามุมภายในและมุมภายนอกข้างเดียวกันของเส้นขนาน) สำเนามุม A หมุนครึ่งรอบไปวางต่อ เติมมุมภายนอกได้พอดี จึงได้ มุมภายนอก = มุม A + มุม B (เพราะ มุม ACB + มุม ACD = 180° และ มุม A + มุม B + มุม ACB = 180°) กด → คำถาม 45° + 65° = 110° (ตัวลวง 70° คือมุมภายในที่ C, 135° = 180° − 45°, 115° = 180° − 65°)

ลากจุดยอดให้นักเรียนสังเกตป้ายตรวจชนิด: ตามด้าน (ด้านไม่เท่า / หน้าจั่ว / ด้านเท่า) และตามมุม (มุมแหลม / มุมฉาก / มุมป้าน) ด้านที่ยาวเท่ากันมีขีดกำกับ และวงเวียนวาดส่วนโค้งจากจุดยอด ผ่านปลายสองด้านที่ยาวเท่ากัน (ระยะจากจุดศูนย์กลางเท่ากันทุกจุดบนส่วนโค้ง) มุมที่ฐานของสามเหลี่ยมหน้าจั่วเท่ากันด้วย กด → ภารกิจ ลากให้เป็นสามเหลี่ยมด้านเท่า (จุดจะดูดเข้ามุม 60° เมื่อเข้าใกล้) กด → คำถาม (180° − 40°) ÷ 2 = 70°
